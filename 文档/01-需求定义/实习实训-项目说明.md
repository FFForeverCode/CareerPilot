后续开发按同目录《需求定义书-开发周期节奏.md》执行。其中的学习任务、外部岗位和模型自由调用工具不在八周基线里。

技术架构设计

本系统采用前后端分离的模块化单体架构，主要由前端展示层、后端业务层、AI应用层、数据访问层及外部大模型服务组成。

1. 前端展示层

前端采用 Vue 3 框架，使用 TypeScript 进行开发，结合 Vite 构建工具、Element Plus UI 组件库、Vue Router 路由管理、Pinia 状态管理及 Axios 网络请求库，实现用户登录、职业档案管理、职业测评、岗位信息展示、AI职业规划和学习任务管理等功能页面。

2. 后端业务层

后端采用 Java 语言和 Spring Boot 框架进行开发，使用 Spring Web MVC 提供 RESTful API 接口，按照 Controller、Service、Repository 分层组织业务代码。

后端主要包括用户与职业档案模块、职业测评模块、岗位信息模块、职业规划模块、学习任务模块和AI应用服务模块。各业务模块通过统一接口进行交互，实现用户信息管理、职业测评结果管理、岗位查询、职业规划保存及学习进度维护等功能。

3. AI应用层

AI应用层采用 LangChain4j 框架接入大语言模型，构建大学生职业规划智能助手。系统通过 Prompt 模板、AI Services、Agent 工具调用及结构化输出等能力，实现职业方向分析、岗位推荐、技能差距分析和个性化学习规划生成。

AI智能体可根据用户职业档案和岗位信息调用相关业务工具，获取系统数据并生成职业规划建议。AI生成结果经过后端校验后保存至数据库，形成职业规划与学习任务管理闭环。

4. 数据访问层

系统采用 SQLite 数据库保存用户信息、职业档案、职业测评记录、岗位信息、职业规划记录及学习任务等业务数据。后端采用 Spring Data JPA 实现数据访问与实体管理，满足实训项目的数据持久化需求。

5. 外部模型服务

系统通过后端统一调用外部大语言模型服务，完成自然语言理解、职业分析及规划生成。模型接口地址、API Key 和相关参数通过配置文件或环境变量进行管理，避免敏感信息暴露在前端及代码仓库中。

6. 系统部署

系统采用单体应用部署方式，前端 Vue 项目构建为静态资源，后端 Spring Boot 项目打包为可执行 JAR 文件，SQLite 作为本地业务数据库。系统通过 HTTP 接口完成前后端通信，并通过后端统一管理大模型调用及业务数据访问。

本系统不采用微服务架构，优先保证系统结构清晰、模块职责明确、开发过程可控和八周实训周期内的交付能力。

## 本期做什么

主链路是：注册并填写档案 → 完成测评 → 查看推荐方向 → 和助手对话 → 生成并打印方案。老师可以看方案并写评语。

系统只有一个对话助手。回答时带上该生档案和最近一次测评。方案必须包含四个标题：【当前情况】【可选方向】【在校安排】【待确认问题】。方向名称只能来自管理员维护的方向库。

六个模块：

1. 用户与学业档案：学生、就业指导老师、系统管理员
2. 职业意向测评：小组自编题目，不是心理诊断
3. 职业规划智能体：Langchain4j 单助手，含失败提示和模拟回复
4. 职业生涯规划方案：保存、查看、浏览器打印、老师评语
5. 发展方向参考：规则推荐，不由模型现编岗位和薪资
6. 公告、参数与统计：统计只看人数和份数，不能点进某一次聊天

## 本期不做什么

八周、5 个人，下面这些写进了“不包含”，后面不要自行加回基线：

- 简历生成、模拟面试打分、招聘网站爬虫和薪资预测
- 多个智能体互相调用，以及向量知识库
- App 和小程序
- 学校统一身份认证、短信和邮箱找回密码
- 心理诊断，以及考研、考公能否录取的预测
- 上传附件、语音和图片

模型没有额度或答辩当天超时，用模拟回复走完演示。模拟回复必须有明显标记，不能伪装成模型生成。
