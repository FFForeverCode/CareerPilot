## 1. 通用约定

### 1.1 统一响应

```json
{
  "success": true,
  "message": "中文提示",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `success` | boolean | 是否成功 |
| `message` | string | 中文提示；失败时给可读原因，**不返回堆栈** |
| `data` | object / array / null | 业务数据 |

HTTP 状态建议：业务失败可用 200 + `success=false`，无权限用 403，未登录用 401。前端以 `success` 和 `message` 为准。

### 1.2 鉴权

| 项 | 约定 |
| --- | --- |
| 方式 | `Authorization: Bearer <token>` |
| 令牌 | JWT；登录后 8 小时无操作失效；退出后原令牌立即失效 |
| 角色 | `student` / `teacher` / `admin` |
| 权限 | **后端强制校验**；前端隐藏菜单只是辅助 |
| 越权 | 返回 403 中文提示，并写一条拒绝日志；响应体不含被拒数据 |

### 1.3 不返回的内容

- 密码明文、bcrypt 哈希
- 模型密钥（只来自环境变量）
- 异常堆栈
- 老师 / 统计 / 日志接口中的 `chat_message.content`

### 1.4 当前前端阶段

第 3 周前端用本地 mock（对齐 `prototype/` 规则）。下文路径是能力合同建议值；正式后端实现时允许调整路径，但请求/响应能力必须覆盖。

## 3. API-01 注册 / 登录 / 退出 / 当前用户

### 3.1 学生注册

`POST /api/auth/register`

```json
{ "studentNo": "20230001099", "password": "Stu123456" }
```

| 规则 | 说明 |
| --- | --- |
| 学号 | 11 位数字，全库唯一 |
| 密码 | 8～16 位，须同时含字母和数字；库中只存 bcrypt |
| 角色 | 固定创建 `student` |
| 成功 | 提示注册成功；**不自动登录**，回到登录 |

失败示例：`学号必须是 11 位数字。` / `该学号已存在，请直接登录或换一个学号。`

### 3.2 登录

`POST /api/auth/login`

```json
{ "studentNo": "20230001001", "password": "********" }
```

成功 `data`：

```json
{
  "token": "<jwt>",
  "user": { "id": 1, "studentNo": "20230001001", "realName": "张小明", "role": "student" }
}
```

| 规则 | 说明 |
| --- | --- |
| 连续失败 | 未满 5 次不锁；第 5 次失败后锁定 15 分钟 |
| 锁定中 | 正确密码也不能登录 |
| 日志 | 登录成功写操作日志（动作：登录） |
| 不返回 | 密码、哈希 |

### 3.3 退出

`POST /api/auth/logout`（需登录）

使当前令牌立即失效。

### 3.4 当前用户

`GET /api/auth/me`（需登录）

返回当前用户基本信息（无密码字段）。

## 4. API-02 重置密码并解锁

`POST /api/admin/users/{userId}/reset-password`（仅 admin）

- 学生 / 老师调用 → 403，并记拒绝日志
- 成功后旧密码不可用；账号解锁（`fail_count=0`，`locked_until` 清空）
- 写操作日志（动作：重置密码）
- 新密码不在网页常驻展示；正式实现由后端生成并仅在当次提示中出现

## 5. API-03 学业档案

### 5.1 读取

`GET /api/profile`（学生本人）

`data` 含档案字段、`completeFlag`、`missing`（缺的必填项中文名）、`phoneMasked`（中间四位隐藏）。

### 5.2 保存

`PUT /api/profile`

| 必填 | 选填 |
| --- | --- |
| 姓名、年级、专业、去向偏好 | 性别、班级、手机号、邮箱、意向城市、自我说明、成绩档次 |

| 规则 | 说明 |
| --- | --- |
| 去向 | 仅 `就业/考研/考公/创业/还没想好` |
| 成绩档次 | 仅 `前 30%/中游/后 30%/未填`；不参与完成判断 |
| 自我说明 | ≤300 字；301 字拒绝，已输入内容由前端保留 |
| 缺必填 | 仍可保存，`completeFlag=0`，`message` 写明缺项 |
| 四项齐全 | `completeFlag=1` |

越权读取他人档案 → 403。

## 6. API-04 / API-05 / API-06 测评

### 6.1 学生作答题列表

`GET /api/assessment/questions`

- 启用题 ≥18：返回全部启用题（一次展示）
- 启用题 <18：`available=false`，文案固定为「题目维护中」

### 6.2 提交答卷

`POST /api/assessment/submit`

```json
{ "answers": { "1": "A", "2": "B" } }
```

| 规则 | 说明 |
| --- | --- |
| 漏题 | 拒绝；不写入半份答案 |
| 计分 | 后端完成，**不调用大模型**；24 题目标 1 秒内 |
| 前两型 | 按六型得分截取；并列按 R、I、A、S、E、C |
| 保留 | 每人最近 3 次；第 4 次删最早一次及明细 |

### 6.3 结果列表

`GET /api/assessment/results`

返回本人最近 3 次（时间、六型得分、前两型、是否并列）。结果页声明原文：

> 本结果只反映本次作答倾向，不能作为心理诊断、保研或录用依据。

### 6.4 管理员题目维护

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/admin/questions` | 题目列表 + 启用数 |
| POST | `/api/admin/questions` | 新增：两选项类型不同且属 RIASEC |
| PUT | `/api/admin/questions/{id}` | 已作答题改选项失败 |
| PATCH | `/api/admin/questions/{id}/enabled` | 启用 / 停用 |

### 6.5 老师测评摘要

`GET /api/teacher/students/{userId}/assessment-summary`

只返回最近一次类型与得分；**不含** `assessment_answer` 逐题选项。

## 7. API-07 对话

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/chat/page` | 会话列表、是否未测评、助手/模拟开关 |
| POST | `/api/chat/sessions` | 新建会话；标题可空 →「新的规划对话」；最长 20 字 |
| GET | `/api/chat/sessions/{id}/messages` | 本人历史消息 |
| POST | `/api/chat/sessions/{id}/messages` | 发送；1～500 字 |
| DELETE | `/api/chat/sessions/{id}` | 逻辑删除 `deleted_flag=1` |
| PATCH | `/api/chat/sessions/{id}` | 改标题（可选） |

| 规则 | 说明 |
| --- | --- |
| 未测评 | 允许聊天；页面出现「尚未测评，生成方案前需要先完成测评。」 |
| 顶部声明 | 「内容仅供规划参考，不代表学校官方意见。」固定不变 |
| 提示词 | 后端组装档案 + 最近测评 + 推荐；模型历史最多 10 轮（20 条） |
| 简历拒绝 | 用户要求写简历/打分时，回复说明做不到，不出现完整简历 |
| 模拟回复 | 打开后回复带 `mock=true`；黄条原文「当前为模拟回复，不是模型生成。」 |
| 失败 | 超时/报错本轮不入库、不自动重试；输入由前端保留 |
| 助手关闭 | 返回「助手维护中」语义；不能发送也不能生成方案 |
| 老师访问消息 | **403**，响应不含 `content`，记拒绝日志 |

## 8. API-08～API-10 方向与收藏

### 8.1 推荐列表

`GET /api/directions/recommend`

计分（仅上架方向，后端计算，不交给模型）：

- 标签与测评前两型每重合一个 +2
- 类别与去向偏好相同 +3（偏好「还没想好」不加）
- 取得分 >0 的前 3 名
- 无测评：不返回推荐列表，只提示先完成测评
- 理由模板示例：「与你本次测评靠前的类型以及档案里的去向偏好更接近」
- **无薪资、无录取概率**

### 8.2 方向维护（管理员）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET/POST | `/api/admin/directions` | 列表 / 新增 |
| PATCH | `/api/admin/directions/{id}/status` | 上架 / 下架 |

名称唯一；类别仅就业/考研/考公/创业；简介 ≤200；两条在校可做的事；无薪资字段；被收藏或方案引用的不能物理删除。

### 8.3 收藏

`POST /api/directions/{id}/favorite`（再点一次取消）

下架方向不能新收藏；原收藏保留并标已下架。

## 9. API-11 / API-12 方案与评语

### 9.1 生成方案前置（后端再查一次）

必须同时满足：

1. 档案 `completeFlag=1`
2. 至少一次测评
3. 推荐至少 1 条（得分 >0）
4. 已保存方案 <5 份

不满足时按钮旁 / 接口提示只写缺的那一条（档案 / 测评 / 推荐 / 份数）。

### 9.2 生成并保存

`POST /api/plans`

```json
{ "sessionId": 1 }
```

| 规则 | 说明 |
| --- | --- |
| 四个标题 | 正文须原样含【当前情况】【可选方向】【在校安排】【待确认问题】 |
| 书名号 | 每个《》内名称必须在方向库 |
| 来源 | `model` 或 `mock` |
| 失败 | 不保存、条数不变、中文提示 |
| 日志 | 成功写「生成方案」 |

### 9.3 列表 / 详情 / 删除

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/plans` | 本人方案：时间、来源、有无评语 |
| GET | `/api/plans/{id}` | 学生本人或老师可读；正文只读 |
| DELETE | `/api/plans/{id}` | 学生删除；需前端确认；连评语删；写日志 |

学生修改正文 → 拒绝。管理员无方案正文入口。

### 9.4 评语

`PUT /api/plans/{id}/comment`（老师）

- 1～200 字；空或超长拒绝
- 一个方案只留最新一条；覆盖前前端确认
- 学生刷新可见；学生不能改评语
- 老师不能改方案正文

## 10. API-13～API-16 公告、参数、统计、日志

### 10.1 公告

| 方法 | 路径 | 角色 |
| --- | --- | --- |
| GET | `/api/announcements` | 学生 / 老师：未下线，置顶在前 |
| GET/POST | `/api/admin/announcements` | 管理员维护 |
| PATCH | `/api/admin/announcements/{id}` | 置顶 / 下线 |

标题 ≤40，正文 ≤500。种子至少一条写明实训演示。

### 10.2 参数

`GET/PUT /api/admin/config`

可改：接口地址、模型名、超时秒数（5～60，默认 30）、助手开关、模拟回复开关、免责声明。

**查询与页面均不含密钥。** `sys_config` 不存密钥。

### 10.3 统计

`GET /api/admin/stats`

四个数字：

1. 注册学生数（含停用，注明「含停用」）
2. 档案完成数
3. 测评人数（至少一次）
4. 方案份数

无「查看对话」、无导出、无消息正文。

### 10.4 日志

`GET /api/admin/logs?userId=&action=`

只记：登录、重置密码、生成方案、删除方案、改题目、改方向、改参数。

字段：操作者、动作、对象类型、对象编号、时间、客户端 IP。详情无聊天正文。学生 / 老师 → 403。
