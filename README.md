# CareerPilot

基于 AI 智能体的大学生职业生涯规划系统。项目编号 SE2313-01，班级软 2313，周期 2026-11-03 至 2026-12-28。

当前仓库有实训文档、页面原型（`prototype/`）和数据库设计（`文档/04-数据库设计/`）；Vue 3 前端、Spring Boot 后端和 SQLite 文件 `career.db` 尚未开始。后续代码按需求定义书放在仓库根目录。模型密钥只放环境变量，不提交。

## 文档目录


| 目录             | 内容                                     |
| -------------- | -------------------------------------- |
| `文档/01-需求定义`   | 需求定义书 Word、开发用基线、项目说明，以及生成 Word 的脚本    |
| `文档/02-需求跟踪矩阵` | 设计用需求跟踪矩阵和说明                           |
| `文档/03-测试成绩书`  | 单体测试成绩书。Excel 记录 OK / NG，Markdown 便于阅读 |
| `文档/04-数据库设计` | 数据库设计说明、建表脚本、种子脚本和验收查询 |
| `文档/模版`        | 课程下发的需求定义书、需求跟踪矩阵和测试成绩书模版              |


开发、联调和测试以 `文档/01-需求定义/需求定义书-开发周期节奏.md` 为准。课程提交仍用同目录的 Word。改功能先改需求基线，再改矩阵、测试用例和代码。
