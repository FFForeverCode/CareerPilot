# CareerPilot 产品原型（静态可点击）

这是按 `文档/01-需求定义/需求定义书-开发周期节奏.md`（V1.2）和 `任务清单.md` 做的**纯前端可点击原型**：不装依赖、不需要后端，打开浏览器就能按角色走完主链路。

- 12 个路由、两套布局（学生 / 管理）、三个角色
- 假数据：3 个学生、1 个老师、1 个管理员、24 道测评题、8 个方向、2 条公告、3 份方案
- 业务规则集中在一个「模拟后端」文件里（`assets/js/mock-api.js`），按钮状态只是辅助，校验以它为准
- 固定原文 T-01～T-10、三个色值 `#1F4E79 / #C47B3A / #F6F4F1` 都按需求基线写死

> 原型用于对齐需求和页面行为，不是最终实现。数据存在浏览器 localStorage，刷新不丢，右上角「重置数据」可恢复种子。

## 1. 怎么打开

**方式一：直接双击**

双击 `prototype/index.html`，用 Chrome 或 Edge 打开即可。

**方式二：起一个本地静态服务（推荐，file:// 下部分浏览器会限制 localStorage）**

```powershell
python -m http.server 8123 --directory F:\CareerPilot\prototype
```

然后打开 <http://127.0.0.1:8123/index.html>。

想直接看某个角色的某个页面，可以用预览跳转页（会先用演示账号登录）：

```text
http://127.0.0.1:8123/tools/preview.html?role=student&route=%23/home
http://127.0.0.1:8123/tools/preview.html?role=teacher&route=%23/teacher/students
http://127.0.0.1:8123/tools/preview.html?role=admin&route=%23/admin/ops%3Ftab%3Dstats
```

## 3. 主链路怎么点

1. 登录页点「学生」快捷登录 → 首页（能看到「教学演示」和固定声明）
2. 学业档案：补全四项必填，看「缺项提示」与手机号脱敏
3. 测评：24 题一次展示，全部答完才能提交 → 结果页看到前两型、六型得分、T-03
4. 方向与收藏：看到按规则打分的前 3 个方向和推荐理由
5. **先切管理员**：公告、参数、统计、日志 → 模型参数 → 打开「模拟回复开关」并保存
6. 回到学生 → 规划对话 → 新建会话 → 发送消息 → 看到黄色提示条「当前为模拟回复，不是模型生成。」
7. 点「生成方案」（强调色按钮）→ 跳转方案详情：四个标题、《》方向名、来源、老师评语
8. 方案详情点「打印」→ 浏览器打印预览去掉侧栏和按钮
9. 切老师 → 学生方案 → 按姓名或学号查 → 打开学生 → 写评语（可覆盖，覆盖前确认）
10. 学生刷新同一方案，能看到老师评语

模拟回复默认关闭是需求要求（FR-M3-04），所以第 5 步不能省；开关关闭时对话和生成方案会走失败分支，这也是有意保留的演示点。

## 5. 原型里已经做进去的验收点

- 登录注册：学号 11 位且唯一、密码 8～16 位含字母和数字、5 次失败锁定 15 分钟、中文错误提示
- 档案：四项必填、缺项提示、成绩只收档次、手机号隐藏中间四位、自我说明 300 字、`complete_flag` 影响生成按钮
- 测评：启用题不足 18 道整页「题目维护中」；一次答完；只留最近 3 次；标准样例 I=6/C=5/R=4/S=4/E=3/A=2 → 研究型、常规型；并列按 RIASEC 顺序并标注
- 推荐：标签每重合一个 +2、类别与偏好一致 +3、得分大于 0 的前 3 名、理由用模板句、无薪资
- 对话：顶部 T-01 固定、未测评仍可聊并显示 T-04、500 字限制、标题默认 T-06 且最长 20 字、删除会话、拒绝代写简历、模拟回复黄条 T-05、助手关闭显示 T-08
- 方案：四项前置条件（档案 / 测评 / 推荐 / 份数）缺哪条写哪条、最多 5 份、四个标题原样检查、《》名称必须在方向库、来源区分 model / mock、正文不可编辑、删除确认、打印样式
- 老师：按姓名或学号查、档案摘要只读、最近一次测评不含逐题答案、无「查看对话」入口、评语 1～200 字且覆盖前确认
- 管理员：题目新增/停用、已作答只能停用不能改选项、方向新增/下架、公告 40/500 字与置顶下线、参数 6 项且超时 5～60 秒、页面无密钥输入、四个统计卡片（含停用说明）、日志只记 7 种动作且可按学生筛、重置密码解锁
- 全站：三个色值、「教学演示」出现在登录页 / 首页 / 方案页、按角色切换两套布局、越权访问在模拟后端返回 403 文案

## 6. 自检

```powershell
# 业务规则 80 项，Node 直接跑，不需要浏览器
node prototype/tools/selfcheck-node.mjs

# 页面渲染 17 项：浏览器打开下面这个页面，标题会变成 RENDERCHECK PASS/FAIL
# http://127.0.0.1:8123/tools/rendercheck.html
```

`prototype/tools/` 下的文件都是自检和预览工具，不影响原型本身：

- `selfcheck.html` / `selftests.js` / `selfcheck-node.mjs`：业务规则测试
- `rendercheck.html`：12 个路由的渲染自检
- `preview.html`：按角色登录后跳到指定页面

`prototype/screenshots/` 是自动截的原型页面图，可以作为需求跟踪矩阵图 1～图 13 的**参考**；矩阵要替换成正式实现的截图，不要直接用原型图。

## 8. 原型和正式实现的差异

| 项 | 原型 | 正式实现（按任务清单） |
| --- | --- | --- |
| 前端 | 原生 HTML/CSS/JS，无构建 | Vue 3 + TypeScript + Vite + Router + Pinia + Element Plus |
| 数据 | 浏览器 localStorage | SQLite `career.db` + Spring Data JPA |
| 权限 | 前端模拟角色检查 | Spring Boot 令牌 + 角色校验，越权返回 403 并记日志 |
| 模型 | 模拟回复（固定话术，按档案/测评/推荐拼装） | Langchain4j 单点调用，失败走模拟回复 |
| 密码 | 明文存在本地原型数据里 | bcrypt 哈希 |
| 打印 | 浏览器打印 + 打印样式 | 同上，服务器不生成 PDF |

对接真前端时，把 `mock-api.js` 的方法换成 Axios 请求、保留函数签名即可；`views-*.js` 的页面结构可以直接拆成 Vue 组件。原型里已经按 `任务清单.md` 第 6.1 节把 12 个路由和两套布局分好了。
